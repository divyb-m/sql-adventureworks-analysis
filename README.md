# AdventureWorks SQL Analysis

## Overview
Multi-table SQL analysis of the AdventureWorks dataset, a Microsoft sample 
database representing a fictional bicycle manufacturing and sales company. 
This project demonstrates JOIN operations across multiple related tables to 
answer real business questions around sales performance, customer behaviour, 
product trends, and returns.

## Dataset
- **Source:** Kaggle — AdventureWorks Dataset for Data Analysis (Maven Analytics)
- **Tables:** 11 tables including sales, customers, products, categories, 
  returns, and territory lookup

## Questions Explored
1. What are the total sales by territory and region?
2. Which customers have placed the most orders?
3. What are the top 10 best-selling products by order quantity?
4. Which product categories generate the most revenue?
5. What is the return rate by product?
6. How do sales compare across 2020, 2021, and 2022?
7. Which territory has the highest average order value?
8. Which customers have never returned a product?
